# AI Systems Portfolio

Personal portfolio for Dan Sleeter.

This is a static site built for GitHub Pages. It contains a home page and three case studies covering AI-assisted workflow design, agent operating rules, and a Python/Playwright automation prototype.

## Files to upload to GitHub

Upload the contents of this folder to the root of the `ai-systems-portfolio` repository:

- `index.html`
- `case-agentic-prior-art.html`
- `case-ip-navigator.html`
- `case-automation.html`
- `styles.css`
- `script.js`
- `README.md`

Do not upload the ZIP file itself. `index.html` should be visible at the top level of the repository.

## Publish with GitHub Pages

1. Open the repository on GitHub.
2. Go to **Settings > Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch **main** and folder **/ (root)**.
5. Save.

Expected project-site format:

`https://<github-username>.github.io/ai-systems-portfolio/`

## Public-content note

The portfolio is intentionally sanitized. Do not add client-confidential matter details, proprietary evidence, non-public data, or sensitive screenshots to the public repository.
