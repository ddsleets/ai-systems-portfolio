## Public portfolio boundaries

This repository is intentionally sanitized.

It does **not** contain customer-confidential material, raw private field data, exact sensitive test coordinates, credentials/API keys, private prompts, unpublished invention details, proprietary EVOLVE Core implementation, private evaluation artifacts, or restricted security implementation.

Experimental AI/RFML results remain attached to their test context and are not represented as production deployment, universal model reliability, autonomous decision authority, or validated real-world RF performance beyond the evidence shown.
