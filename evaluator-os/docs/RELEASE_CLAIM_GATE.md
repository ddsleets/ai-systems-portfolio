# Portfolio Release Claim Gate v0.1

Before any Evaluator OS result is used publicly, verify that the wording matches the earned evidence.

## Allowed now
- experimental evaluator architecture exists;
- three human-verified Gold tasks exist;
- Mission 003 is reviewer-blind and calibration-eligible;
- outcome, authority/safety, and observable trajectory are separated;
- candidate-to-Gold disagreements are preserved and diagnosed.

## Not allowed yet
- general evaluator reliability percentage;
- provider ranking or benchmark superiority claim;
- inter-rater reliability claim;
- judge calibration-performance claim;
- production-ready RFML claim;
- operational government deployment claim;
- API-provider integration claim unless actually implemented and verified.

Any public Case 06 update should pass this gate before G7 release.
